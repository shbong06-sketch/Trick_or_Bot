## 5. Critical Path (일정에 직접 영향을 주는 항목) `[제안]`

지연되면 전체 완료가 밀리는 가장 긴 의존 사슬이다(튜터 Day4 지침: 개수가 줄면 Green, 그대로면 Yellow, 늘면 Red).

1. **하드웨어 점검(G0)**: 두 로봇 환경·지도·초기 위치. 이게 끝나야 이후 모든 시험이 실물에서 돈다 — 10/8 밤.
2. **호박 머리 인식 모델**: 데이터 수집 → 라벨 → 학습 → 선정. M2의 입력이고 통합 ④(10/11~12)의 선행 조건이다. 로봇·아레나·호박 머리가 있어야 시작할 수 있다.
3. **술래 순찰 Nav2(M3)** → 상태기계(M2) → 통합 ④.
4. **게임 서버 API(M6)**: 웹(M7), 도망자 조작(M4), 안전 감시(M8)가 모두 이 API에 기대고 있다.
5. **통합 ④ → G5(3회 연속 성공)**: 이게 되기 전에는 Lv2·3과 아이템에 착수하지 않는다.
6. **10/9 휴무**: 로봇을 쓸 수 없는 날이므로 서버·UI·상태기계를 재생 데이터로 시험하는 계획이 빠지면 10/10 통합 ①이 밀린다.
