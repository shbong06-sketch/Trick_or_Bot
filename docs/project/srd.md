## 1. 요구사항 작성 기준

모든 요구사항은 다음 여섯 가지를 만족하게 쓴다(튜터님 피드백, 발표문서).
**Measurable(측정 가능), Specific(구체적), Achievable(달성 가능), Relevant(BR과 관련), Verifiable(검증 가능), Traceable(추적 가능).**
각 TR에는 합격 기준(수치)과 검증 방법이 있어야 하고, 어느 BR에서 나왔는지(§7 추적표) 알 수 있어야 한다.

## 2. 용어

| 이 문서의 용어 | 뜻 | 다른 문서에서 쓰는 이름 |
|---|---|---|
| 술래 (Seeker) | 자율 로봇. 순찰·의심·추적·체포·수색·복귀를 스스로 한다 | 살인마, 감시 로봇 |
| 도망자 (Runner) | 플레이어가 웹으로 조작하는 로봇. 호박 머리 오브제를 쓴다 | 생존자 |
| 열쇠 / 발전기 | 도망자가 모아야 하는 목표. Lv1은 닿으면 획득, Lv2부터 구역에 일정 시간 머무름 | 열쇠, 발전기 |
| 아레나 | 게임이 진행되는 실내 구역(3 m × 3 m) | 맵 |
| 회차 (Round) | 게임 한 판. 회차 ID로 구분 | 판 |
| 조작석 | 플레이어가 웹 화면을 보며 조작하는 자리 | |

용어 통일은 OI-01에서 팀 결정을 기다린다.

## 5. 기능·성능 요구사항 (TR)

> 필수 = 이번 MVP 합격에 포함, 권장 = 시간이 되면 구현. 합격 기준의 수치는 팀 Notion 그대로다.

|---|---|---|---|---|---|

### 5.5 안전·장애

## 6. 인터페이스 요구 (상위 수준)

세부 토픽·API는 SDD §5에서 정한다.

| 인터페이스 | 요구 |
|---|---|
| 로봇 ↔ 게임 서버 | 두 로봇의 위치와 상태 ≥5 Hz |

| 웹 ↔ 도망자 | WASD 입력 ≥10 Hz, 0.5초 끊기면 정지 |

| 웹 ↔ 내부 노드 | 웹은 게임 서버를 통해서만 접근한다(로봇 노드에 직접 의존하지 않음) |

## 7. 레벨 설정 (요구의 파라미터)

레벨마다 새 요소가 하나씩 추가된다. 도망자 최고 속도는 모든 레벨에서 0.25 m/s로 고정한다. 의심 게이지 칸은 "도망자가 1.5 m에서 계속 보일 때 게이지가 다 차는 시간"이다.
**Lv1이 필수, Lv2·3은 선택, Lv4·5는 설계 참고**로 둔다(OI-03).

| 항목 | Lv.1 첫 번째 밤 | Lv.2 둘레길 | Lv.3 멈춰 보기 | Lv.4 예측 불가 | Lv.5 최후의 밤 |
|---|---|---|---|---|---|
| 새 요소 | 기본 규칙(열쇠 즉시 획득) | 발전기 체류 + 관문 CCTV | 멈춰 둘러보는 술래 + 첫 아이템 | 무작위 순찰 + CCTV 호출 | 은신처 뒤 점검 + 5곳 중 4곳 |
| 술래 순찰 | 위쪽 통로 1자 왕복(P1↔P2) | 중앙 장애물 둘레 작은 루프(L1→L5) | 외곽 큰 루프(P1→P6), 지점마다 2초 멈춰 좌우 90° 확인 | P1~P6과 L1~L5를 매 바퀴 무작위 순서로 방문 | Lv4 + 은신처 A·B·C 뒷편 점검(H1~H3) |
| 술래 속도(m/s) | 0.12 | 0.15 | 0.18 | 0.20 | 0.22 |
| 의심 게이지 만충 시간(s) | 3.0 | 2.5 | 2.0 | 1.5 | 1.2 |
| 수색 | 없음(놓치면 바로 복귀) | 마지막 위치에서 3 s 제자리 회전 | 마지막 위치 + 가까운 은신처 1곳, 6 s | 마지막 위치 + 은신처 2곳, 8 s | 마지막 위치 + 반경 1.5 m 안 은신처 전부, 10 s |
| 발전기(활성 자리) | G3, G4, G5 · 진입 즉시 | G2, G3, G5 · 3 s 체류 | G1, G3, G4, G5 · 4 s | G2, G3, G4, G5 · 5 s | G1~G5 중 4곳 · 5 s |
| CCTV | 없음 | C1(관문) | C1, C2 | C1~C3, 발전기 가동을 보면 술래 호출 | C1~C4 |
| 아이템 | 없음 | 없음 | 가속(I1) | 투명(I2), 모래시계(I3) | I1, I2, I3 |
| 제한 시간 | 4:00 | 3:30 | 3:00 | 3:00 | 2:30 |

맵 설계 7원칙(순환 루프, 시야 대비, 은신처, 발전기 위험도 배치, CCTV 사각, 반드시 지나는 위험 경로, 아이템 배치)은 팀 Notion 발표문서 "레벨 디자인" 절을 따른다. 3 m × 3 m 안에 이 배치가 들어가는지는 실측으로 확인해야 한다(OI-04).
