# 레벨 1 인터페이스

## 담당과 범위

- 주은·은빈: 로봇 위치, 제어, 안전, 게임 규칙, 웹 연결.
- 승현·원호: 펌킨 감지, 관측에 연결된 지도 위치와 거리 계산.
- 성은·민서: 전달받은 위치와 게임 상태를 화면에 표시.
- 레벨 1에서는 웹캠, 자동 복귀, 깊이 기반 위치 추정을 사용하지 않는다.

## 연결

| 이름 | 자료형 | 발행 또는 제공 담당 |
|---|---|---|
| /tob/pumpkin/pose | geometry_msgs/PoseStamped | 펌킨 위치 노드 |
| /tob/boo/pose | geometry_msgs/PoseStamped | 부 위치 노드 |
| /tob/perception/pumpkin_detection | tob_interfaces/TargetObservation | 펌킨 감지 노드 |
| /tob/target/observation | tob_interfaces/TargetObservation | 대상 위치 계산 노드 |
| /tob/game/state | tob_interfaces/GameState | 게임 관리 노드 |
| /tob/game/event | tob_interfaces/GameEvent | 게임 관리 노드 |
| /tob/boo/state | tob_interfaces/BooState | 부 제어 노드 |
| /tob/pumpkin/safety | tob_interfaces/SafetyState | 안전 감독 노드 |
| /tob/boo/safety | tob_interfaces/SafetyState | 안전 감독 노드 |
| /tob/game/command | tob_interfaces/GameCommand | 게임 관리 노드 |

실제 로봇 번호, 카메라 토픽, 속도 명령 토픽은 설정에서 연결한다.
로봇 이름은 pumpkin과 boo, 감지 출처는 boo_camera를 사용한다.

## 좌표와 시각

- 두 로봇 위치는 같은 지도 좌표계를 사용한다. 기본 이름은 map이다.
- 좌표 단위는 미터, 시간 단위는 초이다.
- 위치의 시각은 위치를 얻은 시각을 유지한다.
- 감지의 시각은 원본 영상 촬영 시각을 유지한다.
- 위치를 얻지 못하면 발행을 중단한다. 원점을 대신 발행하지 않는다.
- 소비자는 마지막 위치의 시각으로 만료 여부를 판단한다.
- 실제 장비의 시계를 동기화하고 모의실험의 시간 설정을 통일한다.
- 화면 좌표 변환은 표시 용도로만 사용한다.

## 감지와 추적

- 감지 노드는 새 영상마다 감지 여부를 전달한다.
- 대상이 없으면 detected를 거짓으로 발행한다.
- 감지 노드의 map_valid는 항상 거짓이다.
- 영상이 끊기면 예전 감지를 새 시각으로 재발행하지 않는다.
- 대상 위치 계산 노드는 감지와 두 로봇의 지도 위치를 연결한다.
- 위치의 최신성, 시각 차이, 좌표계, 유한값을 검사한다.
- 감지와 위치 검사를 모두 통과했을 때만 map_valid를 참으로 한다.
- 거리는 두 로봇 지도 위치 사이의 평면 거리로 계산한다.
- 감지 상실 후 숨은 펌킨의 현재 위치를 추적용으로 갱신하지 않는다.
- 부 제어 노드는 마지막 유효 관측 위치를 기억하고 다음 행동을 정한다.
- 오래된 감지는 현재 발견 상태로 인정하지 않는다.

## 게임 규칙

- 게임 관리 노드만 사탕 획득, 잡힘, 성공, 실패를 최종 판정한다.
- 사탕을 모두 모으면 exit_enabled를 참으로 설정한다.
- 탈출 가능 상태에서 탈출존에 들어가면 즉시 성공한다.
- 탈출존에서 기다리는 시간과 탈출문 열림 사건은 사용하지 않는다.
- 제한시간과 잡힘 조건에 따른 실패는 레벨 설정을 사용한다.
- 전체 게임 상태로 획득 사탕, 하트, 탈출 가능 여부를 복원한다.
- 사건은 화면 효과와 기록에 사용한다. 사건 순번은 사용하지 않는다.
- 최종 결과 저장은 라운드 식별자로 중복을 방지한다.

## 게임 명령

- 시작은 준비, 성공, 실패 상태에서 요청할 수 있다.
- 시작 전 준비 조건을 검사하고 새 라운드 식별자를 생성한다.
- 일시정지는 진행 상태, 재개는 일시정지 상태에서만 허용한다.
- 일시정지와 재개에는 현재 라운드 식별자가 일치해야 한다.
- 초기화는 준비 상태로 바꾸고 라운드 식별자를 비운다.
- 기존 라운드가 있으면 초기화에도 해당 식별자가 일치해야 한다.
- 알 수 없는 명령과 지원하지 않는 레벨은 거절한다.
- 일시정지 중에는 게임 시간과 잡힘 누적시간을 멈춘다.
- 일시정지, 종료, 초기화 시 이동 목표를 취소하고 정지한다.
- 명령 수락 응답은 실제 로봇 정지 완료를 보장하지 않는다.
- 재개할 때 예전 조작 명령을 다시 실행하지 않는다.
- 게임 명령으로 비상정지를 해제하지 않는다.

## 통신과 안전

- 프로젝트 상태와 관측은 신뢰성 보장, 과거 자료 미보관, 최신 1개를 사용한다.
- 사건은 신뢰성 보장, 과거 자료 미보관, 최근 10개를 사용한다.
- 카메라 구독 설정은 실제 카메라 발행 설정에 맞춘다.
- 위치, 게임 상태, 부 상태, 안전 상태는 주기적으로 발행한다.
- 감지와 관측은 처리한 새 영상에 맞춰 발행한다.
- 발행 주기와 자료 만료시간은 설정에서 정한다.
- 이동 명령, 게임 상태, 안전 허용 정보가 만료되면 정지한다.
- 안전 허용은 작성 시각과 로컬 수신 중단 시간을 모두 검사한다.
- 오래된 안전 입력에 새 시각만 붙여 이동을 허용하지 않는다.

## 별도로 정할 값

- 시작점, 사탕, 순찰 지점, 탈출존의 지도 좌표와 판정 반경.
- 제한시간, 잡힘 거리와 지속시간, 하트 수, 연속 피격 간격.
- 성공과 실패가 동시에 발생할 때의 우선순위.
- 위치 무효 시 게임 처리, 자료 만료시간, 허용 시각 차이.
- 안전 정지 거리와 잡힘 거리의 관계.

이 값은 level1.yaml과 각 담당 설정 파일에서 정한다.
웹 연결부는 기존 웹 형식과 이 인터페이스 사이를 변환한다.
브라우저 시간 표시에는 남은 시간과 진행시간을 사용한다.
