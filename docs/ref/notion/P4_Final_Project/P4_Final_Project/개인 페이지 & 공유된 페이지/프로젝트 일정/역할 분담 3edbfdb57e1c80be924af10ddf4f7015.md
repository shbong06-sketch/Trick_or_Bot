### 하드웨어 특성

#### 웹캠

1. 고정 위치 및 각도, RGB 카메라
2. 삼각대에 고정해서 RC카 위치를 볼 수 있는 곳에 배치
3. 카메라 선 짧으니까 주의할 것
4. 리눅스 치즈 툴? → 카메라 포트 통해서 이미지 따오기 가능 or 코드 만들어서 진행 (예시 코드 깃허브에 있음)
    
    ![image.png](%EC%97%AD%ED%95%A0%20%EB%B6%84%EB%8B%B4/image.png)
    
5. 그냥 영상 → 이미지 캡쳐 후 저장하기가 끝

#### AMR 카메라:

1. AMR에 따라 움직임, 각도 변경 가능, RGB-D 카메라
2. 이미지가 토픽으로 날라옴
3. 토픽 발행하게 해야 함 + 뭐가 되는지도 찾아야 함 + 무슨 토픽 쓸건지 결정하기 + 어떤 규모로 이미지 가져올건지 (YOLO 학습이랑 같게 설정?)
4. Depth 측정 가능한 것 활용하기: 차랑 거리 ~cm일 때까지 다가가기
5. 근데 RGB 이미지랑 Depth 이미지 다를 수 있음 ⇒ 두 이미지가 pixel-pixel align이 되어야 함 (둘의 이미지가 같게끔) → config 파일에서 dimension만 바꿔서 진행할 것 (width / height) → 이거 진행 후 데이터 수집 수행
