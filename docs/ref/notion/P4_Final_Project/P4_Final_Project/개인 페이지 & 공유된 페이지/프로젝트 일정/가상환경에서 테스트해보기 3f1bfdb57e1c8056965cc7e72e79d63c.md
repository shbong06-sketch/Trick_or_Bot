# 가상환경에서 테스트해보기

날짜: 2026년 10월 6일

```jsx
unset ROS_DISCOVERY_SERVER ROS_SUPER_CLIENT
export ROS_DOMAIN_ID=77      # 다른 사람과 겹치지 않는 아무 번호
ros2 daemon stop
```

```jsx
ros2 launch turtlebot4_gz_bringup turtlebot4_gz.launch.py \
  namespace:=robot2 localization:=true nav2:=true rviz:=true
```

공통 준비 (새 터미널마다)

```jsx
unset ROS_DISCOVERY_SERVER ROS_SUPER_CLIENT
export ROS_DOMAIN_ID=77
source ~/rokey_ws/install/setup.bash
```

- 모든 노드에 --ros-args -r __ns:=/robot2가 필요합니다.
- 노드 하나가 끝나면 로봇이 도크로 돌아간 것을 확인한 뒤 다음 노드를 실행하세요.
- 대부분 노드가 도크 확인 → 언독 → 초기 위치 (0,0) 설정 → Nav2 대기 순서로 시작합니다.

---

1. nav_to_pose: 목표 한 곳으로 이동
    
    `ros2 run day3 nav_to_pose --ros-args -r __ns:=/robot2`
    
2. nav_through_poses: 여러 지점을 멈추지 않고 통과
    
    `ros2 run day3 nav_through_poses --ros-args -r __ns:=/robot2`
    
3. follow_waypoints: 지점마다 정지하며 이동
    
    `ros2 run day3 follow_waypoints --ros-args -r __ns:=/robot2`
    
4. create_path: RViz에서 직접 경로 찍기
    
    `ros2 run day3 create_path --ros-args -r __ns:=/robot2`
    
5. mail_delivery: 번호를 입력해서 원하는 곳으로 이동
    
    `ros2 run day3 mail_delivery --ros-args -r __ns:=/robot2`
    
6. patrol_loop: 배터리를 보며 무한 순찰
    
    `ros2 run day3 patrol_loop --ros-args -r __ns:=/robot2`
    

---

1. sim_depth_checker: 화면 중앙의 거리(m)를 계속 출력해요.
    
    `ros2 run day3 sim_depth_checker --ros-args -r __ns:=/robot2`
    
2. sim_depth_to_3d: 화면 중앙 점의 좌표를 camera → base_link → map 순서로 변환해서 출력해요.
    
    `ros2 run day3 sim_depth_to_3d --ros-args -r __ns:=/robot2 -r /tf:=/robot2/tf -r /tf_static:=/robot2/tf_static`
    
3. sim_depth_to_nav_goal: 화면 중앙 점의 map 좌표로 이동해요.
    
    `ros2 run day3 sim_depth_to_nav_goal --ros-args -r __ns:=/robot2 -r /tf:=/robot2/tf -r /tf_static:=/robot2/tf_static`
    
    → "Control" 창을 클릭한 뒤 g 키를 누르면 목표가 전송돼요. 도착하면 노드가 종료돼요.
    
4. sim_nav_to_person: YOLO로 사람을 찾으면 그쪽으로 따라가요.
    
    `ros2 run day3 sim_nav_to_person --ros-args -r __ns:=/robot2 -r /tf:=/robot2/tf -r /tf_static:=/robot2/tf_static`
    

---

1. depth_checker: 클릭한 픽셀의 거리를 확인해요.
    
    `ros2 run day3 depth_checker --ros-args -r __ns:=/robot2`
    
2. depth_to_3d: 클릭한 픽셀을 map 좌표로 변환해요.
    
    `ros2 run day3 depth_to_3d --ros-args -r __ns:=/robot2 -r /tf:=/robot2/tf -r /tf_static:=/robot2/tf_static`
    
3. depth_to_3d_ts: 2번과 같은데, RGB와 depth 영상의 시간을 맞춰서(Time Synchronized) 처리해요.
    
    `ros2 run day3 depth_to_3d_ts --ros-args -r __ns:=/robot2 -r /tf:=/robot2/tf -r /tf_static:=/robot2/tf_static`
    
4. depth_to_goal: 클릭한 지점으로 로봇이 이동해요.
    
    `ros2 run day3 depth_to_goal --ros-args -r __ns:=/robot2 -r /tf:=/robot2/tf -r /tf_static:=/robot2tf_static`
    
5. depth_to_goal_ts: 4번과 같은데, 시간을 맞춘 버전이에요.
    
    `ros2 run day3 depth_to_goal_ts --ros-args -r __ns:=/robot2 -r /tf:=/robot2/tf -r /tf_static:=/robot2/tf_static`
