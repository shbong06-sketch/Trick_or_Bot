## 우리 프로젝트의 잘한 점

1. **[업무 분담]** 노드별로 역할 분담하여 모두가 코드작성에 참여하였고, 단위테스트(웹캠/AMR캠/Nav2)를 빠르게 끝냄
2. **[Localizer]** AMR 카메라로 획득한 ArUco Marker의 **Map 좌표**와 웹캠에서 검출한 동일 Marker의 **픽셀 좌표**를 대응시켜 Homography를 계산하였다. 이를 통해 실제 로봇의 Map 좌표를 기준점으로 활용하여 **웹캠 픽셀 좌표의 Map 좌표 변환 정확도를 향상시켰다.**
3. **[follow]** 추종을 ‘픽셀 좌우 오차 + depth 거리만으로 작동’으로 빠르게 끝내고 nav2 브랜치도 구현 완료 (모든 이동이 Nav2로 장애물 회피에 용이함)
4. **[네트워크 경량화]** 
    1. AMR 카메라에서 토픽은 car만 발행하여 필요한 토픽만 발행하도록 함
    2. AMR 카메라에서 5hz로 이미지를 받아옴
5. **[예외 처리_배터리]** 배터리가 20퍼 미만으로 떨어질 때 도킹이 되도록 함
6. **[예외 처리_detect]** 2초동안 한번도 detect되지 않는다면 회전하며 찾는 로직이 있음
7. **[예외 처리_잘못된 좌표 발행 방지]** 보정점, 해상도, 감지 시간, 유한값 및 Homography 변환 유효성을 검증하여 **비정상적인 입력을 사전에 차단하고 신뢰할 수 있는 좌표만 발행**하도록 구성하였다.
8. **[예외처리_안전거리]** `distance <= min_distance`에서 정지: 앞의 운반차에 너무 가까워졌을 때 충돌 위험을 줄임.
