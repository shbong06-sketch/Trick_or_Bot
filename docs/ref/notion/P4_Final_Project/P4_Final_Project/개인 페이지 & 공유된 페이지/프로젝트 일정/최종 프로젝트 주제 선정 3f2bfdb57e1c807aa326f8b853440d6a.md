        - 한 AMR이 순찰 중 의심 물체를 탐지하면 해당 위치와 Detection 정보를 다른 AMR에 전달한다. 두 번째 AMR이 현장으로 이동해 근거리에서 재탐지·검증하여 오탐 여부를 최종 판단한다
