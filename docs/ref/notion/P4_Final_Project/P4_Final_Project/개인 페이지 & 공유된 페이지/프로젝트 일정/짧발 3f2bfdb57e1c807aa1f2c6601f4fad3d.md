# 짧발

날짜: 2026년 10월 7일

1. 최종 프로젝트 주제
- **주제**
    
    현장을 자율주행하며 실제 시공 상태를 인식하고, BIM/설계 정보와 비교하여 시공 오차와 누락을 조기에 탐지하는 시스템을 구현할 것
    
- **문제 심각성**
    
    건설 현장에서 실제 시공 상태가 설계와 다르게 구현될 경우, 늦게 발견할수록 재작업 비용과 공정 지연이 커지는 문제를 해결하고자 함.
    
- **상업적 요구사항**
    
    반복적인 현장 검사를 자동화하고 시공 오차를 조기에 발견하여 재작업과 검사 비용을 줄일 필요가 있다.
    
- **기술적 요구사항**
    
    로봇이 현장을 자율주행하면서 구조물과 설비를 인식하고, 인식된 객체의 실제 위치를 설계/BIM 기준과 비교할 수 있어야 한다.
    
- **솔루션**
    
    AMR + Detection + ROS2를 이용하여 실제 시공 상태를 자동으로 수집하고, 설계 데이터와 비교하여 이상 위치를 자동으로 기록하는 Autonomous Reality Verification System을 구축한다.
    
1. 팀의 장점:  **팀워크와 역할 밸런스가 좋았으며, 개발 경력자가 2명 있어 안정적으로 프로젝트를 진행할 수 있음**
2. **원하는팀: 원활하게 소통하며 자유롭게 의견을 공유하고, 함께 즐겁게 협업할 수 있는 팀원**
