- **정의**
    
    현장을 자율주행하며 실제 시공 상태를 인식하고, BIM/설계 정보와 비교하여 시공 오차와 누락을 조기에 탐지하는 시스템
    
- **문제**
    
    건설 현장에서 실제 시공 상태가 설계와 다르게 구현될 경우, 늦게 발견할수록 재작업 비용과 공정 지연이 커질 수 있다. [ASCE](https://www.asce.org/publications-and-news/civil-engineering-source/article/2026/01/22/how-much-does-field-rework-in-construction-actually-cost?utm_source=chatgpt.com)
    
    *현장의 현재 방식*
    
    - 감리·검측자가 도면을 기준으로 체크리스트를 만들고, 현장에서 이를 들고 확인한 뒤 사진으로 기록합니다. 실제 발주 문서에도 현장 검측은 체크리스트를 사용해 수행하고 그 결과를 검측 체크리스트에 기록하도록 되어 있습니다. [g2b](https://www.g2b.go.kr/pn/pnp/pnpe/UntyAtchFile/downloadFile.do?bidPbancNo=R25BK01083653&bidPbancOrd=000&fileType=&fileSeq=2)
    - 천장 설비는 사다리나 고소작업대에 올라가 눈과 줄자로 확인해야 해서, 층·세대 수만큼 반복 노동이 생깁니다.
    
    *문제의 크기*
    
    - 검측이 형식적으로 흐르고 있습니다. 한 전문가는 공기 단축 압박과 인력 부족으로 검측이 형식적으로 진행되는 경우가 있고, 감리 업체가 인건비 구조 때문에 적정 인력을 배치하지 못한다고 지적합니다. 실제로 LH 무량판 현장의 81%가 법정 감리 인원을 충족하지 못했습니다. [seoulfnseoulfn](https://www.seoulfn.com/news/articleView.html?idxno=638586)
    - 인력 사정도 나빠지고 있습니다. 건설사 대상 조사에서 기술인력 부족의 가장 큰 원인은 감리 강화와 소비자 요구 다양화로 인한 업무량 증가(43%)였습니다. 또 2026년 4월 기준 건설기능인력의 평균 연령은 51.9세입니다. [cerik](https://www.cerik.re.kr/uploads/report/2990/%EA%B1%B4%EC%84%A4%ED%98%84%EC%9E%A5%20%EA%B8%B0%EC%88%A0%EC%9D%B8%EB%A0%A5%20%EB%B3%80%ED%99%94%20%EB%8F%99%ED%96%A5%EA%B3%BC%20%ED%99%95%EB%B3%B4%20%EB%B0%A9%EC%95%88.pdf)[nate](https://m.news.nate.com/view/20260611n03925?sect=eco&list=rank&cate=interest)
    
    *피해(시간·돈·인력)*
    
    - 재작업의 상당 부분은 정보 불일치에서 나옵니다. 미국 조사에서 재작업의 48%가 부정확한 프로젝트 데이터와 의사소통 오류 때문이었고, 미국 전체로 연 313억 달러 규모로 추정됐습니다. [autodesk](https://www.autodesk.com/blogs/construction/construction-disconnected-fmi-report/)
    - 같은 조사에서 현장 인력은 근무시간의 35%(주 14시간 이상)를 정보 찾기, 갈등 해결, 실수와 재작업 처리 같은 비생산적 활동에 쓰고 있었습니다. [autodesk](https://www.autodesk.com/blogs/construction/construction-disconnected-fmi-report/)
    - 천장을 막은 뒤 누락이 발견되면 천장재를 뜯고 다시 시공해야 하고, 소방 완공검사와 후속 공정도 늦어집니다.
- **상업적 요구사항**
    
    반복적인 현장 검사를 자동화하고 시공 오차를 조기에 발견하여 재작업과 검사 비용을 줄일 필요가 있다.
    
- **기술적 요구사항**
    
    로봇이 현장을 자율주행하면서 구조물과 설비를 인식하고, 인식된 객체의 실제 위치를 설계/BIM 기준과 비교할 수 있어야 한다.
    
- **솔루션**
    
    AMR + Detection + ROS2를 이용하여 실제 시공 상태를 자동으로 수집하고, 설계 데이터와 비교하여 이상 위치를 자동으로 기록하는 Autonomous Reality Verification System을 구축한다.

- **솔루션**
    1. **저가 AMR 기반 실시간 시공 검증 시스템**: 로봇이 현장을 돌며 설비를 인식하고, 그 자리에서 간이 BIM과 비교해 오차·누락을 판정하여 곧바로 소통
    2. **Spot 로봇이 비싼 이유**: 다리 4개에 관절이 12개라 고성능 모터와 감속기가 12세트 필요, 균형 제어 → 부품 정밀도 + 내구성 요구 높음 + 수요가 적어서 비싸짐
    3. **업로드되어 있는 BIM 업데이트하여 설계와 비교하기**: 설계 단계에서 세대 평면 변경, 용도 변경, 지반이 생각과 달라 기초나 기둥 변경 등 다양하게 이뤄지는데 이런 기초적인 부분부터 철근의 개수 등은 저가의 AMR가 평지를 돌아다니며 확인하는 형태로도 충분할 것 
    4. TurtleBot 4 기반 저가 AMR이 현장을 반복 순찰하면서 RPLIDAR로 자율주행하고, OAK-D Pro로 구조물·설비의 존재 여부와 위치를 인식하여 최신 BIM/설계 데이터와 비교하는 1차 자동 검증 시스템 
    5. 정밀 측량을 대체하는 것이 아니라, 사람이 정밀검사를 하기 전에 AMR이 넓은 현장을 자주 순찰하며 “누락·오배치·큰 시공 편차”를 먼저 걸러내는 저비용 1차 검증 시스템
    6. 예를 들면 데모도:
        - 설계상 있어야 할 배관이 없음 → **누락**
        - 기둥/벽 mock-up이 기준 위치에서 10 cm 이동 → **위치 편차**
        - 잘못된 설비가 다른 위치에 있음 → **오배치**
        - BIM 업데이트 전/후를 비교 → **변경 설계 반영 여부 확인**

### 하드웨어 및 시스템 역할

- **TurtleBot 4**: 건설 현장을 자율주행하며 검사 지점으로 이동하는 AMR 플랫폼
- **RPLIDAR A1M8**: SLAM, Localization, Navigation 및 장애물 회피
- **OAK-D Pro**: RGB 기반 객체 인식과 Depth 정보를 이용한 구조물의 3D 위치 추정
- **ROS2**: Nav2, TF, Detection, 데이터 기록, 기준 모델 비교 등 전체 시스템 통합

### 시스템 동작 과정

1. **기준 모델 생성**
    
    BIM 또는 설계 데이터를 기반으로 벽, 기둥, 배관 등 구조물이 있어야 할 기준 위치를 저장
    
2. **검사 위치로 자율주행**
    
    TurtleBot 4가 RPLIDAR와 Nav2를 이용해 지정된 검사 지점으로 이동
    
3. **현장 객체 인식 및 거리 측정**
    
    OAK-D Pro로 구조물·설비를 Detection하고 Depth 정보를 획득
    
4. **실제 위치 계산**
    
    ROS2 TF를 이용해 카메라 좌표계의 객체 위치를 Map 좌표계로 변환
    
5. **설계값과 비교**
    
    측정된 실제 객체 위치와 BIM/기준 모델의 설계 위치를 비교
    
6. **시공 편차 판정**
    
    설정한 허용오차를 초과하거나 객체가 누락된 경우 **Deviation Detected**로 기록
