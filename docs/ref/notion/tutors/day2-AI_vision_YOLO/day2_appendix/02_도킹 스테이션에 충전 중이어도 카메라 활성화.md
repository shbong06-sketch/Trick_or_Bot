### 1. 도킹 스테이션에 충전 중이어도 카메라 활성화

- ssh로 turtlebot ubuntu에 접속하기

```bash
ssh ubuntu@[터틀봇 ip 주소]
```

- 비밀번호: turtlebot4

```yaml

cd /opt/ros/jazzy/share/turtlebot4_bringup/config

#원본 백업
sudo cp turtlebot4.yaml turtlebot4_origin.yaml

#설정
sudo nano turtlebot4.yaml

```

**power_saver: True  → False로 수정**

```yaml
turtlebot4_node: 
  ros__parameters:
    wifi:
      interface: "wlan0"

    # Setting power_saver to True will make the TurtleBot 4
    # disable the camera and lidar while docked
    power_saver: False  

    # Supported Functions:
    # Dock
    # Undock
```

```yaml
sudo reboot
```
