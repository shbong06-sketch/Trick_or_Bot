# 1. Executive Summary

## 1.1 대상 고객과 상황

대상 고객은 가동 중인 공장·물류센터의 생산기술·설비·시설관리팀이다. 증설·설비 이전·배치 변경의 계획과 변경 후 현황 갱신 과정에서 현재 시설·객체 배치를 확인하고 관계자와 공유하는 업무를 지원한다. BMW·Audi의 공개 사례에서 생산시설 현황의 취득·조회·계획 활용과 변경 후 갱신이 확인된다. 우선 이용 시나리오는 변경 전후 조사이며, 국내 고객의 실제 수행 방식·이용 빈도·구매 구조는 추가 확인한다.

**근거: 2.1.1~2.1.2, 2.2.1, 4.1~4.2.**

## 1.2 핵심 문제

설비 및 시설 구조 변경 이후 기존 자료와 실제 현황의 불일치를 확인하고 자료를 갱신하는 데 현장 방문·측정·처리·검토 부담이 발생한다. 공개 사례는 이러한 업무 부담과 공간 정보 활용의 개선 가능성을 뒷받침하지만, 국내 목표 고객의 평균 손실 규모를 입증하지는 않는다. 본 사업은 이 중 반복 갱신과 회차 간 변경 확인 부담에 초점을 둔다. 객체별 변경 목록의 필요성과 실제 비교 부담은 고객 조사로 확인할 가설이다.

**근거: 2.3.1~2.3.2.**

## 1.3 제안 솔루션

「SLAM·객체 탐지 기반 산업 실내 레이아웃 변화관리 시스템」을 제안한다. 두 대의 로봇이 지정 구역을 분담하여 RGB-D 영상의 특징점을 활용한 위치 추정과 점군 기반 3차원 지도 갱신·화면 표시를 조사 중 수행한다. 회차별 지도에 지정 객체의 위치·관측 이미지·시각을 연결하고, 공통 좌표계에서 추가·이동·제거 후보를 제공한다. 이동은 동일 객체 대표점의 바닥 평면 위치 변화로 평가하며, 미관측·정합 불량·대응 모호 상태와 사용자의 확인 이력을 함께 남긴다.

**범위·업무 흐름: 3장, 6장.**

## 1.4 기대 가치

기대 가치는 최신 현황의 조회·공유, 변경 검토와 후속 확인 대상 선정의 지원, 반복 조사·정리·검토 부담의 감소이다. 기존 방식과 동일한 업무·필수 정보 품질 조건에서 준비·감독·개입·처리·검토·재조사를 포함한 총 인시와 조회·변경 판정 성능을 비교하여 개선 여부를 판단한다. 시간 단축과 현금 비용 절감은 구분하며, 고객 직접 운영과 조사 서비스 이용의 총 부담 비용을 각각 평가한다.

**가치·경제성 검증 기준: 2.2.4, 2.3.4, 4~5장.**

## 1.5 이번 프로젝트의 검증 목표

지정 실내 시험 구역과 승인된 객체를 대상으로 실시간 위치 추정·3차원 점군 지도 갱신·표시, 두 로봇 결과의 공통 좌표 통합, 회차별 저장·조회와 변경 후보 검토를 구현·검증한다. 무변경·추가·이동·제거·가림·중단 시나리오에서 지도 품질, 객체 위치 오차·기록 완전율, 변경 정밀도·재현율, 실시간 주기·지연과 운영자 개입을 측정한다. 기준 방식 대비 총 인시·검토 부담·후속 회차 준비 부담도 평가한다. 목표 수치와 반복·합격 조건은 기초 시험과 기준선 확인 후 인수 시험 전에 확정한다.

**검증 지표·인수 기준: 5장, 10장.**

## 1.6 결론과 조건

공개 사례로 현황 확보·갱신·공유의 업무 존재는 뒷받침되므로, 보유 장비로 현황 취득과 객체 변경 검토를 연결하는 프로젝트 검증을 추진한다. 사업화 판단에는 기존 대안 대비 추가 가치, 국내 고객의 반복 이용·구매 의향, 필요한 정보 품질과 총 비용에 대한 증거가 더 필요하다. 주행·관측·통신 조건, 회차 정합 기준과 독립 평가 자료를 확보한 범위에서 시험하며, 월간 장기 운영·대규모 산업 현장 적용성과 비용 우위는 이번 시험의 달성 결과로 주장하지 않는다.

**수행기간·사업비:** 본 프로젝트의 수행기간은 과정 일정 5~10차시(설계 1차시, 개발 4차시, 발표 1차시)이며 상세 일정은 14장을 따른다. 사업비는 교육기관 제공 장비·시설을 사용하며 별도 예산 편성은 없다. 사업화 단계의 재원 구성은 16장에서 항목만 정의하고 금액은 미확보로 둔다.

**범위·기술 전환 기록:** 본 문서의 대상·기술 범위는 10/2 초안에서 전환된 것이며 결정 기록은 9.4 O-00에 둔다.

**추진 조건·추가 검증: 4.7, 8~10장, 13장.**

### 2.1.1 고객 업무

관련 고객 업무는 현재 배치를 확보하여 변경 계획에 활용하고, 변경된 현황을 자료에 반영하는 과정이다. BMW 공식 자료는 현황 조회·측정·공유와 개조 후 재스캔을, Audi 공식 자료는 생산시설 스캔의 가상 조립·신규 차종 계획 활용을 설명한다. BMW — 2022년 발표 · Audi — Smart Production, 2022 [S-01, S-02]

다음 표는 이 업무와 본 사업을 연결한 분석이다. 역할 명칭은 목표 고객 조사에서 확정하며, 고객별 취득 도구·산출물·수행 방식은 2.2.1에서 정리한다.

### 2.1.4 적용 환경

사업 대상인 "가동 중인 공장·물류센터"는 시설의 사용 상태를 뜻한다. 로봇이 생산·운반 작업과 동시에 조사할 수 있다는 의미로 사용하지 않는다. Audi는 생산시설 스캔을 야간·주말 등에 수행한 사례를 공개했다. 이는 운영 중인 시설에서도 조사 시간대의 조정이 필요할 수 있음을 보여주며, 모든 현장이 같은 조건이라는 근거는 아니다. Audi — Smart Production [S-02]

#### 자료로 확인된 영향 요인

NavVis 공식 기술 문서는 이동 객체가 관측 가림·영상 흐림·점군 잡음을 만들 수 있고, 정적 특징이 부족하거나 반복적인 공간에서 이동 객체의 영향이 커지면 SLAM 품질이 저하될 수 있다고 설명한다. 대형 설비 주변의 취득 지침도 관측 가림과 복수 관측 위치의 필요성을 다룬다. Moving objects · Large machines [S-19, S-20]

#### 현장 확인 항목

다음 항목과 확인 방법은 공식 자료의 영향 요인 및 보유 장비 구성(8장)을 바탕으로 작성한 현장 검증 계획이다. 수치 기준은 장비 확인과 시험 후 결정한다.

#### 적용 판단

초기 검증은 주행 가능한 평탄 구역, 통행을 조정할 수 있는 시간대, 관측 가능한 지정 객체와 반복 정합 기준이 확보되는 조건에서 수행하는 방안을 제안한다. 이는 사업 전체의 적용성이 검증되었다는 의미가 아니다.

적용 여부는 현장별 경로·관측·통신 조건과 요구 정보 품질을 확인한 뒤 결정한다. "실내" 또는 "바닥 평탄"이라는 분류만으로 조사 가능성을 확정하지 않는다. 미관측·접근 불가 구역은 결과에 남기고, 추가 조사 또는 적용 범위 축소 여부를 판단한다.

자료 검토로 환경 영향 요인과 조사 시간대 조정 사례는 확인되었고, TurtleBot4·보유 센서의 제조사 사양은 8장에 정리했다. 목표 현장의 조건, 센서 탑재 상태의 가동시간과 실환경 허용 범위, 3,000~20,000㎡ 대상의 완주·정합·품질과 동시 작업 환경에서의 운용 가능성은 현장 시험이 필요한 상태이다.

### 2.1.5 핵심 기술 과제

이번 프로젝트는 영상 특징점을 위치 추정·재방문 인식에 활용하고 깊이 관측을 누적하여 점군 기반 3차원 지도를 생성하는 방향으로 설정한다. RTAB-Map 계열 공식 자료는 RGB-D 기반 SLAM, 외관 기반 재방문 인식(루프 클로저)과 점군 지도 출력을 설명하며 구현 접근의 예로 삼는다. 구성 확정은 O-09에서 하며, 이는 보유 장비의 실시간 성능·정확도가 확보되었다는 뜻이 아니다. RTAB-Map · ROS 2 공식 저장소 [S-21, N-09]

핵심 기술 과제는 실제 배치 변화와 관측·추정 오류를 구분하여, 회차 간 비교 결과의 신뢰성을 확보하는 것이다. 관련 연구도 회차별 지도 정합, 변경 탐지, 기록 관리를 별도 과제로 다룬다. (Lifelong 3D Mapping Framework for Hand-held & Robot-mounted LiDAR Mapping Systems [S-22]. 해당 연구는 LiDAR 기반이며 과제 구분의 근거로만 인용한다.)

특히 객체 탐지와 동일 개체 식별은 다른 문제이며, 영상 내 Tracking ID만으로 회차 간 객체 대응을 보장할 수 없다. (RIO: 3D Object Instance Re-Localization in Changing Indoor Environments [S-23])

검증은 배치를 바꾸지 않은 반복 조사부터 시작한다. 이후 알려진 이동, 추가·제거, 가림, 유사 객체 재배치 순으로 시험하여 좌표 반복성, 잘못된 변경 보고, 개체 대응과 변경 판정 성능을 확인한다. 이는 프로젝트 시험 제안이며 10.1·14장과 같은 순서다.

기술 과제의 존재는 논문·공식 문서로 확인되었다. 깊이 측정·센서 보정·통신 부하에 관한 위험은 제조사 사양과 문헌을 근거로 9.3에 등급을 기록했으며, 보유 장비에서의 실제 발생 여부는 본 프로젝트 시험으로 확인한다. 보유 장비의 위치 정확도, 최소 검출 가능 이동량과 변경 판정 신뢰성도 본 프로젝트 시험으로 확인하며, 허용 오차는 KPI-08의 절차로 결정한다.

## 2.2 As-Is / Baseline

공개 사례를 바탕으로 현행 업무와 개선 효과를 비교할 기준선을 검토한다. 고객의 현행 업무(As-Is), 유사 대안 비교, 프로젝트 시험 기준선을 구분하며, 국내 목표 고객의 실제 방식이 확인되기 전에는 수동 조사를 대표 사업 기준선으로 확정하지 않는다.

**사업 기준선:** 목표 고객이 현재 사용하는 취득·갱신·검토 방식과 산출물을 확인한 뒤 선정한다. 공개 사례는 후보 선정의 근거이며, 국내 목표 고객의 확정된 기준선은 아니다.

**유사 대안 비교:** 자율 로봇 스캔을 주요 비교 대상으로 포함한다. 객체별 추가·이동·제거 판정과 변경 목록 제공은 연계 소프트웨어·업무를 포함하여 확인한다. 이동형 스캔과 디지털 공간 열람 방식도 같은 고객 목적을 지원하므로 함께 비교한다. 휴대형 스캔은 직접 보유하지 않으므로, 로봇 센서를 사람이 들고 같은 경로를 반복 이동하는 간이 대조로 사람 보행의 비재현성을 근사한다. 간이 대조는 상용 휴대형 장비와 동일하지 않으며 결과에 그 한계를 명시한다.

**프로젝트 시험 기준선:** 동일 시험 구역에서 재현·측정 가능한 방식으로, 담당자가 줄자·사진·체크리스트를 이용해 지정 객체의 위치·상태를 기록하는 수동 실측 비교군을 선정한다. 비교군은 동일 구역·객체·변경 시나리오에서 위치표·사진·변경 목록을 산출하며, 인원·측정 절차·산출물 형식은 테스트 요구사항에서 확정한다(O-08). 수동 시험 결과만으로 스캔 이용 고객의 비용 절감이나 시장 대안 대비 우위를 주장하지 않는다. 직접 시험하지 못한 대안은 공개 자료 기반 비교로 표시한다.

### 2.2.4 비교 조건과 미확인 항목

2.2.3에서 선정한 기준 방식과 제안 방식이 같은 고객 업무에 필요한 결과를 제공하는지, 그 과정의 시간·인시·비용과 검토 부담이 어떻게 다른지 비교한다. 아래 조건은 공개 자료를 바탕으로 설계한 비교·검증 계획이며, 고객 요구나 시험 결과가 확정되었다는 의미는 아니다.

#### 비교 목적과 적용 원칙

비교 업무는 지정 구역의 변경 후 현황을 갱신하고 이전 기록과 비교하여, 지정 객체의 추가·이동·제거 후보와 후속 확인 대상을 검토하는 과정으로 설정한다. 현황 갱신의 효율과 변경 후보 제공의 추가 가치를 구분하여 평가한다.

장비와 파일 형식을 동일하게 제한하지 않고 고객 업무에 필요한 정보와 품질을 기준으로 비교한다. 고정밀 3D 모델·CAD/BIM과 본 프로젝트의 점군 기반 3차원 지도·객체 기록을 동등한 결과물로 전제하지 않는다. 고객이 3D 간섭 검토나 CAD 도면을 필요로 한다면 그 결과를 확보하는 추가 업무까지 포함하거나, 해당 목적에 부적합한 방식으로 표시한다.

NavVis의 부분 재스캔은 취득 이후 기준점 정합·처리·게시를 거치고, 공식 품질 보고서는 정합과 기준점 성능 등을 기록한다. 따라서 비교 범위는 취득에서 결과 제공·품질 확인까지로 설정한다. 재스캔 흐름 · 품질 보고서 [S-07, S-30]

취득 방식 비교에는 각 방식의 정상적인 장비·운영 절차를 적용한다. 변경 후보 기능만 평가할 때는 동일한 취득 자료로 현황 조회만 제공한 경우와 변경 후보를 함께 제공한 경우를 비교한다. 검토자 비교 실험은 검토자별로 두 조건의 제시 순서를 맞바꾸는 순서 상쇄(counterbalancing)를 적용하고, 같은 변경 시나리오를 두 조건에서 중복 노출하지 않도록 시나리오 쌍을 교차 배정한다. 이는 학습·순서 효과를 상쇄하기 위한 설계이며 순서 효과의 통계적 검출을 목적으로 하지 않는다. 반복 횟수·검토자 수는 시험 요구사항에서 정한다.

상용 장비의 정확도 수치를 객체 위치 오차나 최소 검출 이동량으로 전용하지 않는다. 예를 들어 BLK ARC의 실내 ±10mm는 통제된 환경·2분 스캔·1σ 조건의 사양이다. 우리 장비와 대안 모두 측정 대상·환경·좌표 기준·통계 지표를 명시한다. Leica 공식 사양 [S-31]

## 2.3 Solution Needs / Pain Point Analysis

2.1의 업무·정보 활용과 2.2의 수행 사례를 바탕으로 해결할 문제, 필요한 업무 결과와 가치를 도출한다. 기존 대안도 현황 취득·열람·공유·갱신을 지원하므로, 본 사업의 필요성은 **기존 방식에 더해 줄일 수 있는 부담**으로 판단한다.

## 4.3 현재 방식의 비용 구조

현행 방식은 2.2.3의 고객 유형과 실제 사용하는 업무·산출물에 따라 선정한다. 수동 조사, 이동형 스캔, 자율 로봇 스캔과 외주 이용 중 한 방식을 전체 시장의 기준선으로 확정하지 않는다.

**회차별 현행 비용 = 참여자별 실제 투입 인시 × 해당 인건비의 합 + 회차에 귀속되는 장비·소프트웨어·처리·저장·이동·외주 비용**

**표 4-4. 현행 방식 비용 구조와 확보할 자료**

| 항목 | 확보할 자료 |
| --- | --- |
| 준비·현황 취득 | 조사 구역·인원·일정, 이동·동행·감독·개입 인시와 취득 시간 |
| 처리·갱신·공유 | 정합·검수·점군 게시·객체 기록·CAD 등 업무 자료 반영 인시와 처리비 |
| 변경 검토·후속 확인 | 이전 자료 비교·판단 보류 검토·재방문·추가 측정 인시 |
| 실패·재작업 | 중단·처리 실패·재취득·복구의 빈도와 추가 인시·비용 |
| 초기 구축·공유 자원 | 초기 지도·기준점·교육·설정과 장비·플랫폼 이용 조건, 다른 업무와의 비용 배분 근거 |

현행 방식과 제안 방식은 동일 고객 업무·필수 정보 품질·조사 구역·반복 횟수로 비교한다. 파일 형식이나 산출물 이름이 같아야 한다는 뜻은 아니다. 필요한 CAD/BIM 반영 등 후속 작업은 양쪽에 포함한다. 기존 부분 조사·부분 갱신도 정상 절차로 인정한다.

경과시간과 총 인시는 별도로 측정한다. 무인 처리 시간을 인시로 계산하지 않으며, 외주 견적에 포함된 인건비·처리비를 다시 더하지 않는다. 초기 구축비·자산 구입액·회차 배분비는 구분하여 중복 계상을 방지한다.

UniCarriers를 조사한 2014년 석사논문은 스캔 활용이 작업 기간을 줄이더라도 도면 재작성 비용은 증가할 수 있다고 분석한다. 이는 시간 단축이 비용 절감과 동일하지 않음을 보여주는 특정 사례이며 국내 현행 단가로 사용하지 않는다. 정량 자료는 2.2.4를 참조한다. Rex·Stoli, §6.3 [S-26]

외부 사례와 장비 사양은 목표 설정의 참고 자료이며 본 프로젝트의 기준선 또는 달성 성능으로 간주하지 않는다. UniCarriers의 기간·비용은 2014년 특정 공장의 도면 재작성 추정값이다. Luxonis의 깊이 오차와 BLK ARC의 지도 정확도는 측정 대상·조건·통계 기준이 다르다. RTAB-Map의 영상 입력률과 지도 노드 추가율도 위치 출력률·점군 화면 갱신률과 구분한다. 목표값은 기초 시험과 업무 활용 기준을 확인한 뒤 인수 시험 전에 확정한다.

## 10.1 공통 시험 조건

- 장비·소프트웨어·모델 버전을 기록한다.
- 구역·객체 수·배치·조명·주행 조건을 기록한다.
- 객체 대표점·기준 좌표·변경 정답을 사전에 확정한다.
- 정합·객체 대응·평면 위치 변화에 따른 변경 판정의 평가 기준을 시험 전에 고정한다.
- RGB-D 동기화·정렬·보정, SLAM 설정·연산 배치·점군 규모·표시 구성을 기록한다.
- 3차원 지도 기준 자료·평가 구역과 위치 추정·지도 갱신·화면 표시의 주기·지연 측정 구간을 사전에 확정한다.
- 개별 로봇의 실시간 지도와 두 로봇의 통합 결과를 구분하여 검증한다.
- 무변경·추가·이동·제거·가림·중단 조건을 포함한다(순서는 2.1.5).
- 준비·감독·개입·복구·검토 인시를 빠짐없이 기록한다.
- 실패 실행을 제외하지 않고 원인과 재시험을 구분한다.
- 안전 확보 인력과 실제 업무 수행 인력을 구분한다.
- 13장의 안전·촬영 고지 절차를 적용하고 기록한다.

## 10.2 미달성 처리

- 필수 요구사항 미달: 수정 후 관련 항목 재시험
- KPI 미달: 결과 공개 후 범위·목표 조정 또는 조건부 수용 여부 결정
- 조건부 수용: 미달 항목·적용 조건·사용자 영향·후속 조치 명시
- 시험 미수행: 미검증으로 표시
- 변경 비교 미달: 현황 조사 기능과 변화관리 기능의 달성 수준을 구분
- 목표 변경: 변경 사유·승인자·버전을 남기고 기존 결과를 보존

# 11. Example Use Cases

## Case1 — 정기 현황 조사와 변경 검토

- **사용자와 목적:** 시설관리 담당자가 이전 회차 대비 배치 변경을 확인한다.
- **시작 조건과 실행 계기:** 기준 회차가 저장되어 있고 정기 조사 또는 변경 이후 조사를 요청한다.
- **정상 흐름:** 조건 지정 → 촬영 고지·안전 확인 → 실시간 위치 추정·점군 지도 갱신·표시 → 회차 결과 통합·저장 → 객체 평면 위치 기반 회차 비교 → 변경 후보 검토 → 확인 이력 저장
- **예외 흐름:** 가림·정합 실패·모호한 객체 대응은 미확인으로 표시하고 재조사를 요청한다.
- **완료 결과:** 현재 3차원 점군 지도·객체 기록·변경 후보·확인 이력
- **관련 요구사항 ID:** BR-T01~12,19~22

## Case2 — 조사 중단과 부분 결과 기반 재조사

- **사용자와 목적:** 운영자가 조사를 중단하고 남은 범위를 확인한다.
- **시작 조건과 실행 계기:** 통행 불가·운영 상황 변화·하드웨어 안전 신호·중단 요청이 발생한다.
- **정상 흐름:** 중단 절차 → 결과 보존 → 미완료 범위 확인 → 재조사 → 회차·부분 결과 관계 저장
- **예외 흐름:** 재조사 결과의 정합이 불충분하면 통합을 보류하고 활용 제한을 표시한다.
- **완료 결과:** 부분 결과·중단 사유·재조사 결과·미완료 목록
- **관련 요구사항 ID:** BR-T06~07,12~18

# 17. Glossary

- 회차: 한 번의 조사 실행 단위. 기준 회차는 비교의 기준이 되는 회차.
- 대표점: 객체의 위치를 한 점으로 요약한 좌표. 이동 판정은 대표점의 바닥 평면 투영 거리로 한다(O-11).
- 정합: 서로 다른 회차·로봇의 지도와 기록을 같은 좌표계로 맞추는 작업.
- 기준점: 정합·검증을 위해 실측 좌표를 갖는 물리 표식.
- 재방문 인식(루프 클로저): 이전에 본 장소를 다시 인식해 누적 오차를 보정하는 SLAM 기능.
- 점군: 깊이·거리 센서가 측정한 3차원 점의 집합.
- 미관측: 조사 경로·시야에서 관측되지 않은 상태. 제거와 구분한다.
- 변경 후보: 사용자 확인 전의 추가·이동·제거 판정.
- hazard(Create 3): 범퍼·절벽·바퀴 들림·후진 한계 등 베이스가 `hazard_detection` 토픽으로 내는 안전 신호. 정체(STALL)는 메시지 정의에 있으나 문서의 센서 목록에는 없음.
- 이동형 영상정보처리기기: 개인정보 보호법 제25조의2의 용어. 사람이 신체에 착용·휴대하거나 이동 가능한 물체에 부착해 촬영하는 장치. 촬영 사실 표시 방법은 시행령 제27조의2.
- 프로젝트 시험 기준선: 2.2.3의 수동 실측 비교군. 사업 기준선(고객 현행 방식)과 구분한다.
