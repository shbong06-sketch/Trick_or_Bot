## A. 깊이 정확도

대상: `depth_checker.py`

카메라 정면의 평판까지 기준 거리를 측정하고, 영상 중앙 픽셀의 깊이와 비교한다.

| 항목 | 계획 |
| --- | --- |
| 거리 조건 | 0.5, 1.0, 1.5, 2.0, 3.0m |
| 측정 위치 | RGB·Depth가 정렬된 영상 중앙의 평판 영역 |
| 안정화 | 대상 배치 후 3초 |
| 표본 수 | 조건별 새로운 Depth 프레임 100개 |
| 반복 횟수 | 거리별 3회 |
| 전체 표본 수 | 5거리 × 100프레임 × 3회 = 1,500개 |

**수행 절차**

1. 로봇을 정지시키고 평판을 첫 거리 조건에 배치한다.
2. 정해진 카메라 기준면부터 평판까지 거리를 측정한다.
3. 명목 거리와 별도로 실제 측정한 기준값을 기록한다.
4. 영상 중앙의 평판을 클릭한다.
5. 서로 다른 Depth 프레임 100개를 저장한다.
6. 무효값도 삭제하지 않고 기록한다.
7. 모든 거리 조건을 측정한 뒤 전체 과정을 3회 반복한다.

카메라 내부의 정확한 기준면을 알 수 없다면 사용한 기준면을 보고서에 명시한다. 기준 거리 측정의 불확실성도 함께 기록한다.

**저장 항목**

```
실험번호,반복번호,Depth시각,기준거리_m,픽셀_x,픽셀_y,측정깊이_m,유효여부
```

**평가 지표**

```
오차 = 측정 깊이 − 기준 거리
평균 절대오차 = 평균(|오차|)
평균 절대오차율 = 평균 절대오차 / 기준 거리 × 100
무효 비율 = 무효 프레임 수 / 전체 프레임 수 × 100
```

평균 오차로 과대·과소 측정 경향을, 표준편차로 측정값의 흔들림을 평가한다.

## B. 지도 좌표 정확도

대상: `depth_to_3d.py`

독립적으로 위치를 확인한 표식의 지도 좌표와 변환 결과를 비교한다.

| 항목 | 계획 |
| --- | --- |
| 기준 대상 | 지도 좌표를 확인한 고정 표식 3개 |
| 로봇 위치 | 같은 표식을 볼 수 있는 위치 3곳 |
| 표본 수 | 조건별 새로운 프레임 100개 |
| 반복 횟수 | 조건별 3회 |

**수행 절차**

1. 표식의 기준 지도 좌표를 측정하고 기록한다.
2. 로봇을 첫 관측 위치에 정지시킨다.
3. 표식을 클릭하고 변환 좌표를 저장한다.
4. 로봇 위치를 바꿔 같은 표식을 측정한다.
5. 나머지 표식에서도 반복한다.

**저장 항목**

```
표식번호,로봇위치,영상시각,기준_x,기준_y,측정_x,측정_y,측정_z,TF성공여부
```

평면 위치 오차는 다음과 같이 계산한다.

```
위치 오차 = √((측정 x − 기준 x)² + (측정 y − 기준 y)²)
```

이 실험 결과에는 깊이 측정, 카메라 정렬, TF, 로봇 위치 추정의 오차가 함께 포함된다. 독립적인 기준 지도 좌표를 확보하지 못하면 **정확도 대신 반복성**을 평가한다.

## C. 동기화 효과 비교

대상: `depth_to_3d.py`, `depth_to_3d_ts.py`

동일한 고정 표식을 관측하면서 정지 상태와 움직임 상태를 비교한다.

| 조건 | 수행 방법 |
| --- | --- |
| 정지 | 같은 위치에서 표식 관측 |
| 이동 | 사전에 정한 저속으로 동일 경로 이동 |
| 회전 | 표식이 영상 안에 유지되도록 동일 각도 구간 회전 |

각 조건에서 일반 버전과 `_ts` 버전을 각각 3회 측정한다. 움직임 속도와 경로는 기록하고 동일하게 유지한다.

**저장 항목**

- 실제 처리에 사용한 RGB와 Depth의 타임스탬프
- 두 메시지의 시각 차이
- 변환 지도 좌표
- TF 변환 성공 여부
- 처리된 프레임 수와 처리율

좌표 오차와 좌표 흔들림을 비교한다. 처리율도 함께 제시해 동기화 과정에서 처리된 데이터 양의 차이를 확인한다.

## D. 이동 정확도

대상: `depth_to_nav_goal.py`, `depth_to_nav_goal_ts.py`

장애물이 없는 바닥에서 두 버전의 목표 좌표와 도착 결과를 비교한다.

| 항목 | 계획 |
| --- | --- |
| 목표 지점 | 기준 지도 좌표를 확인한 바닥 지점 3곳 |
| 출발 위치 | 매회 같은 위치와 방향 |
| 반복 횟수 | 목표별·버전별 5회 |
| 전체 이동 횟수 | 3목표 × 2버전 × 5회 = 30회 |

**수행 절차**

1. 로봇을 출발 위치에 배치하고 위치 추정을 안정시킨다.
2. 목표를 클릭하고 전송된 지도 좌표를 저장한다.
3. 목표 전송 시각을 기록한다.
4. 이동 완료 또는 실패 결과를 기록한다.
5. 최종 위치 추정값을 저장한다.
6. 바닥 표식과 로봇의 정해진 기준점 사이 오차를 직접 측정한다.
7. 로봇을 출발 위치로 되돌려 반복한다.

**평가 항목**

| 지표 | 의미 |
| --- | --- |
| 목표 좌표 오차 | 클릭으로 생성된 목표와 기준 목표의 차이 |
| 위치 추정 기준 도착 오차 | 전송 목표와 최종 위치 추정값의 차이 |
| 실제 도착 오차 | 기준 목표와 직접 측정한 로봇 위치의 차이 |
| 이동 시간 | 목표 전송부터 완료까지의 시간 |
| 성공률 | 성공 횟수 ÷ 전체 시도 횟수 |

목표 좌표 자체의 오차와 목표까지 이동하는 과정의 오차를 각각 기록한다. 목표 방향은 현재 코드의 `yaw=0`으로 통일한다.

**8. 데이터 관리 및 결과물**

조건별로 실험 ID를 부여하고 다음 자료를 함께 보관한다.

```
실험 ID/
  조건표
  측정 CSV
  실행 로그
  rosbag
  대상 배치 및 기준 거리 사진
```

최종 보고서에는 다음을 포함한다.

- 거리별 평균 오차, 평균 절대오차, 표준편차, 무효 비율
- 지도 좌표 변환 오차와 관측 위치별 차이
- 일반 버전과 `_ts` 버전의 동기화·좌표 성능 비교
- 이동 목표 오차, 실제 도착 오차, 이동 시간, 성공률
- 실험 조건과 기준 측정의 불확실성

실험은 **깊이 측정 → 지도 좌표 변환 → 동기화 비교 → 이동 검증** 순서로 수행한다. 허용 오차가 별도로 정해져 있지 않으므로, 우선 측정 결과를 제시하고 실제 작업에서 요구하는 정밀도와 비교해 사용 가능 여부를 판단한다.
