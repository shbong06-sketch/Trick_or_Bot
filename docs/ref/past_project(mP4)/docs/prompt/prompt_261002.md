각 로그의 저장 경로는 result_<작업테마명을_짧게>/임.
나와 당신이 진행하는 주요 작업이 "/home/mu-01/ROKEY_mP4_A1/rokey_ws/src"에서 주로 이루어질텐데, 그 안의 패키지 디렉터리 단위로 위의 result 디렉터리를 각각 만들어서 기록을 저장하는 규칙을 세우겠음.
터미널 기록은 result_<작업테마명을_짧게>/log_<작업테마명을_짧게>/에,
rosbag 기록은 result_<작업테마명을_짧게>/bag_<작업테마명을_짧게>/에 저장되도록 설정할 것.

내가 다른 작업 테마를 진행할 때에도 규칙에 따라 새롭게 기록 저장소를 만들어주면 됨.
git의 경우 feature/cl은 전적으로 당신에게 배정한 branch임.
add, commit, push, pull을 모두 수행해도 됨.
단, 다른 브랜치는 열람만 가능하며, pull의 경우 내가 따로 지시하지 않는 이상 반드시 origin/feature/cl하고만 진행할 것.
이 규칙들은 모두 claude.md에 나와 당신이 잘 이해될 수 있도록 당신이 기록하도록하고 이번만 승인함.
